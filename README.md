# 🎓 CampusSaathi

**Your Campus. Your Language. Your AI Companion.**

CampusSaathi is a multilingual, voice-enabled campus assistant that helps students access college-related information in English, Telugu, and Hindi.

## 🚀 Live Application

[Open CampusSaathi](https://campussaathi-frontend.onrender.com)

## 📄 Project Documentation

[View One-Page Solution Pitch](CampusSaathi_Solution_Pitch.pdf)

## ✨ Key Features

- Voice-based interaction
- English, Telugu, and Hindi language support
- College FAQ-based information retrieval
- Text and audio responses

## 🛠️ Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Python, FastAPI
- Speech-to-Text: Gnani Prisma API
- Text-to-Speech: Gnani Timbre API
- Deployment: Render
